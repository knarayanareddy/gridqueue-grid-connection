# C-T21-T23 · TASK REPORT — Offline application pack and gate-on vs gate-off A/B

Owner: fullstack-agent · Branch: `arena/d4ff3fb9-gridqueue-grid-connection` · Base: `de79314` (PR #2 merged)

**Short version.** The pack generator and the A/B job are built and tested. **Neither has run in a Token Factory
Sandbox.** This environment has no Nebius credentials and can reach only github/pypi/npm. The pack is written to
run as a Sandbox guest command (stdlib only, network-off guard), and the runbook below lists the documented REST
calls. The A/B arms ran as two branches of one snapshot inside a local process, and the result file says so.

## WHAT

**Backend**
- `backend/app/sandbox/pack.py` (new; C-T21/C-T22):
  - `make_bundle(query_response, doc_texts)` → one JSON bundle holding the `QueryResponse` and the exact text
    of every retrieved document.
  - `verify_bundle` re-hashes every document (SHA-256 of its UTF-8 bytes). A citation counts as verified only if
    it is `source_document`, its sha256 matches the document, and its quote passes GQ-QUOTE. Geo/postcode
    citations are excluded (`not_source_evidence`).
  - `build_pack(bundle)` re-runs every asserted value through `DeterministicGate` against the hash-verified text:
    claim quote, indicative date (it must also equal the claim's date), available kW, binding statement, option
    routes and option kW. **Any failure raises `PackVerificationError` and no bytes are produced.**
  - On success it returns `PackResult(content, sha256, manifest)`. The manifest lists `values_verified`, each
    with its document sha256, plus `citations_included` and `citations_excluded`.
  - The output is Markdown with these sections: SYNTHETIC/demo banner, disclaimer, request, the operator's
    determination with its quote and full document sha, the application block for the DSO (Enexis/Liander/Stedin)
    with each non-firm or congestion-management route quoted in Dutch with capacity and evidence, a Dutch request
    letter, a nl/en phone script, the verified sources and a verification table.
  - The bytes are deterministic for a given bundle: no timestamps or environment details are rendered.
  - `assert_network_disabled()` follows the Sandboxes docs: `/sys/class/net` must contain only `lo`, otherwise
    `NetworkEnabledError`.
  - CLI: `python -m app.sandbox.pack --bundle B --out P [--manifest M] [--require-network-off]`. Exit 0 = written,
    2 = withheld (nothing written), 3 = network present.
  - Imports only the stdlib and `app.gate.gate`. A test enforces this.
- `backend/app/stages/s5_answer.py`:
  - `AssembleAnswer(verify=False)` is the gate-off arm. Model proposals are accepted as they are; only an unknown
    `document_id` is refused, because no answer could be built from it. `gate.checks_run` stays 0.
  - When a verified option kW comes from a quote other than the route quote, it now gets its own citation (D-018).
- `backend/app/pipeline.py`: `run_stages()` (S1–S3 → `RunContext`) and `query_response()` are split out of
  `answer_query()`, so both arms start from one snapshot. `answer_query()` has no gate parameter.
- `backend/app/main.py`: `GET /v1/ab-results` serves `runs/ab_experiment_results.json`. It returns 404 with
  "Run `make ab`" if the file is missing.
- `schemas/core-schemas.json` → **v1.3.0**, additive: `$defs/AbExperimentResult`. If `token_factory_sandbox` is
  true, the schema requires `environment: token_factory_sandbox`, an image UUID, ≥2 operation ids and
  `network_disabled` to be set; a local result can't claim to be a Sandbox run.

**A/B (C-T23)**
- `data/fixtures/synthetic/ab/adversarial_cases.json`: **SYNTHETIC**, `"_synthetic": true`, 29 hand-written
  cases with 36 labelled values over the two synthetic operator documents. Each case is one model proposal in
  the S3 extraction schema, plus labels.
  - Groups: G genuine (4), D fabricated dates (10), K fabricated kW (6), B fabricated binding (2), R fabricated
    routes (2, 3 values), M misattributed (5).
  - Fabrication patterns covered:
    - dates added to real sentences that have no date;
    - invented sentences carrying a date;
    - wrong quarter, wrong year, invented precision;
    - a date asserted where the document says none is known;
    - kW figures added to sentences with no figure, a 250 → 2500 magnitude error, an option kW changed 60 → 80;
    - invented binding and "onder voorbehoud" sentences;
    - invented energy-hub and collective routes.
- `jobs/ab_branch_eval.py`:
  - For each case, S1–S3 run once, with a `CaseExtractor` returning that case's proposal. Each arm then gets a
    deep copy of the context: `gate_on` = `AssembleAnswer()`, `gate_off` = `AssembleAnswer(verify=False)`.
  - The snapshot digest is checked before and after the arms, and a mutated snapshot is an error.
  - For each labelled value, the job records whether it reached the **final answer** in each arm.
  - Counters: four `fabricated_*`, `misattributed` and `genuine`, plus the SPEC's four counters as
    `spec_counters`.
  - `--check` exits 1 unless `gate_on` passes 0 fabricated values, `gate_off` passes all of them (a true
    bypass), and `gate_on` keeps every genuine value.
  - Writes `runs/ab_experiment_results.json` (committed; `make ab`).
- Makefile: `make ab`.

**Frontend**
- `frontend/src/App.tsx`: two tabs, "Direction Card" (the existing view, kept mounted so a query survives a tab
  switch) and "A/B Gate Evidence".
  - The tabs follow the ARIA tab pattern with ←/→ keys.
  - The evidence tab loads `/v1/ab-results` on first open and shows:
    - two banners: SYNTHETIC test set, and local process, not a Token Factory Sandbox;
    - the headline;
    - a counter table with gate OFF / gate ON columns and paired bars (solid = off, outlined = on, so the arms
      can be told apart without colour);
    - "What this does not show" (the limitations);
    - per-case details with each label, whether it reached the answer in each arm, and the gate reasons;
    - test-set sha and snapshot id.
- `frontend/src/types.ts`: `AbExperimentResult` types.
- `frontend/src/app.css`: tab and evidence styles, using `var(--…)` tokens only. `tokens.css` is untouched.

```
  gate_off  fabricated_dates=10/10  fabricated_kw=6/6  fabricated_binding=2/2  fabricated_routes=3/3  misattributed=5/5  genuine=10/10
```

How to read it honestly:
- The numbers are **partly by construction**: we wrote a set that contains fabrications, then showed the gate
  removes them. They show *which patterns* the gate stops and that it keeps genuine values (0 false rejects). They
  do **not** measure how often a real model invents dates. SPEC R7 (gate-off might invent nothing on real output)
  is still untested, and so is the 60-query real-output run.
- **Finding: the gate misses misattribution, 4 of 5.** The gate checks that a value is *stated* in the quote, not
  what the sentence *means*:
  - M01: the publication date (14 juli 2026) is presented as the availability date.
  - M02: the "vanaf 60 kW" threshold is read as available capacity.
  - M03: the consumption limit of 250 kW is asserted for feed-in.
  - M04: a `binding` claim is backed by the date sentence. "indicatief" is only a displayed marker, the inflected
    "indicatieve" is not matched, and only `EXPLICIT_NON_BINDING` terms force `non_binding` (DISCREPANCIES 20).
  - Only M05 (a route of the wrong kind) is blocked.

  The UI always shows the quote next to the value, which is the current mitigation. Not fixed in this ticket.

**Pack (C-T21/C-T22)**
1. Locally, build the bundle with `make_bundle(query_response, ctx.doc_texts)` and write `bundle.json`.
2. Put `backend/app/__init__.py`, `backend/app/gate/`, `backend/app/sandbox/` and `bundle.json` into the guest
   with spawn `files: {"/w/...": {"uuid": <uploaded file uuid>}}`. **`TODO_VERIFY(sandbox-file-upload)`: the
   upload endpoint that returns that uuid was not found in the docs.** The SDK's `files=` argument uploads with
   content-hash dedup, so the SDK is the likely route. The image must contain Python 3.11+:
   `TODO_VERIFY(sandbox-python-image)`. The docs only show `tag:busybox:latest`. Do any setup with networking
   on, save the image, and record its UUID, because tags are mutable.
3. `POST v1/instances` with:
   ```json
   {"image": "<saved image uuid>",
    "command": "cd /w && python -m app.sandbox.pack --bundle bundle.json --out pack.md --manifest manifest.json --require-network-off",
    "shell": true,
    "networking": {"enabled": false},
    "disposable": false,
    "preserve_env": false}
   ```
   → 201 `{uuid}`. Networking defaults to **true**, so it must be set on every operation.
4. Poll `GET v1/operations/{id}` (honour `Retry-After`) until `SUCCESS`. Then require `exit_code == 0`,
   `timed_out == false`, and `signal` null or -1. Per the branching guide, an API `SUCCESS` alone proves nothing.
   - Exit 3 means the guest had a network interface: the run is invalid.
   - Exit 2 means the pack was withheld: the stderr lists the failures.
5. `GET v1/inspect/{result_image_uuid}/download?path=/w/pack.md` (and `manifest.json`). Check that the sha256 of
   the downloaded bytes equals both `manifest.sha256` and a local `build_pack(bundle).sha256`.
6. Only then may `Answer.artifact` be filled (`generated_in_sandbox: true`, image UUID, sha256). Today it stays
   `null` (DISCREPANCIES 18).
