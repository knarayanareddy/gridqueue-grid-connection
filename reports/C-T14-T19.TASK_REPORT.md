## WHAT

**Backend**
- `backend/app/stages/base.py` — `StageResult` + `Stage` protocol (protocol §3).
- `backend/app/stages/context.py` — `RunContext`: per-request state shared by the stages.
- `backend/app/stages/s1_resolve_location.py` — deterministic postcode → DSO:
  - 5600–5658 Enexis/Eindhoven, 1000–1099 Liander/Amsterdam, 3000–3089 Stedin/Rotterdam (inclusive).
  - Accepts `5612`, `5612AB` and `5612 ab`. Anything else abstains (`malformed_postcode` / `unmapped_postcode`).
  - Each DSO citation is marked UNVERIFIED.
- `backend/app/tools/tavily.py`:
  - `build_queries()` builds runtime queries from the source register's `discovery_queries_nl` for
    `dso_congestion_register` and `dso_codeerprognose`: DSO name + Dutch direction word + gemeente.
  - `TavilyClient.search()` / `.extract()` use httpx and Bearer auth, with the parameters from the Tavily API
    reference. Every call writes one ledger line (`tavily.search` / `tavily.extract`), success or failure.
- `backend/app/stages/s2_retrieve.py` — live mode: search restricted to the DSO domain, client-side domain
  re-check, top 3 by score, then extract. Each page becomes a `SourceDocument` with sha256, `retrieved_at` and
  `direction_split_available`. Fixture mode loads the SYNTHETIC documents.
- `backend/app/stages/s3_extract.py`:
  - `LiveExtractor` calls Nemotron Ultra via the Token Factory OpenAI-compatible API with `response_format`
    `json_schema`, temperature 0, and the strict `EXTRACTION_SCHEMA`. It writes a ledger line with token counts.
  - `ReplayExtractor` replays recorded SYNTHETIC model output.
  - Invalid output gives no claims, then an abstention.
- `backend/app/stages/s5_answer.py` — deterministic gate + answer assembly (no LLM):
  - Runs every quote, date, publication date, kW, binding statement and option route through
    `DeterministicGate` and drops what fails.
  - Builds the verdict, the binding chip and the deterministic option ranking.
  - Produces `NO_OFFICIAL_POSITION_FOUND` with the lexicon §5 Dutch phone script, plus the determinism hash.
- `backend/app/pipeline.py` — S1 → S2 → S3 → S5. `choose_mode()`: live only with both keys and mocking off.
- `backend/app/main.py` — `POST /v1/answer` (`postcode`, `power_kw > 0`, `direction` feed_in|consumption)
  returns a `QueryResponse`. External services are injected through the `service_factory` dependency, and tests
  override it.
- `schemas/core-schemas.json` → **v1.2.0**: adds `$defs/QueryResponse` (`answer`, `documents`, `citations`,
  `retrieval`). Additive only.

**Fixtures (SYNTHETIC — written by this project, not operator publications)**
- `data/fixtures/synthetic/` contains `README.md`, `index.json` (`"_synthetic": true` is enforced by the
  loader), 2 invented documents and 4 hand-written model outputs:
  - **Enexis:** a clean pass, with Q3 2028 stated as non-binding.
  - **Liander feed-in:** deliberately adversarial. It invents 2027-Q2 and fabricates a binding quote, 500 kW, a
    whole claim and a route.
  - **Stedin:** no document.

**Frontend** (`npm run build` clean; only existing dependencies, now locked in `frontend/package-lock.json`)
- `frontend/src/App.tsx`:
  - Form: postcode, kW, direction radio. Requests can be cancelled (AbortController) and results announce in an
    `aria-live` region.
  - **Direction Card**: top verdict badge (e.g. **"Q3 2028 — Non-binding forecast"**), verdict status, headline,
    and the non-binding markers found.
  - Collapsed **official-quote pill** (`<details>`): verbatim Dutch quote, document, publisher, URL, retrieved
    time and SHA-256.
  - **Ranked flexibility option cards** (non-firm connection / curtailment, flex contract, congestion
    management): stated kW, and the route quoted verbatim.
  - **No-position card** with a "Copy Dutch script" button.
  - **Gate report**: rejected claims, with reasons.
  - SYNTHETIC banner and a retrieval footer.
  - The binding chip can be told apart without colour (icon + border style + label).
- `frontend/src/app.css` — colours are only `var(--…)` from `tokens.css`; tints use `color-mix()`. No emoji
  icons and no Tailwind colours. `tokens.css` is untouched.
- `frontend/vite.config.ts` (proxies `/v1` to `127.0.0.1:8000`; host `0.0.0.0`; `allowedHosts`),
  `tsconfig.json`, `index.html`, `src/main.tsx`, `src/types.ts`, `src/vite-env.d.ts`.

**Tests** (40 new; 155 total)
- `backend/tests/test_s1_resolve_location.py`: range boundaries at both ends, normalisation, malformed input,
  contract validity.
- `backend/tests/test_tavily.py`: httpx `MockTransport` checks the endpoint, Bearer header, exact request
  bodies, ledger lines (validated against `LedgerLine`, key not leaked), HTTP 401/429/432/500 and network
  errors.
- `backend/tests/test_answer_api.py`: every response is validated against `$defs/QueryResponse`.
  - Fixture scenarios: Eindhoven feed-in and consumption, Amsterdam with every fabrication rejected, Rotterdam
    and unmapped postcodes abstaining, 422 on bad input, a stable determinism hash.
  - Live path, with Tavily mocked and the model stubbed:
    - Off-domain results are rejected.
    - An invented date is dropped.
    - A paraphrased quote gives `NO_OFFICIAL_POSITION_FOUND`.
    - On a Tavily failure the answer abstains, with no fixture fallback and no model call.
  - The real `LiveExtractor` is exercised with a stub OpenAI client (request shape, ledger, tokens), including
    invalid model output (`schema_violation`).
- **Mutation check:** I replaced `DeterministicGate.evaluate` in S5 with "always PASS". 3 tests then failed
  (`test_invented_date_and_fabrications_rejected_by_gate`, `test_live_invented_date_is_dropped`,
  `test_live_paraphrased_quote_gives_no_official_position`), so the tests fail if the gate is removed.
